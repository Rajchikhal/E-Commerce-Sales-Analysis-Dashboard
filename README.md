# E-Commerce Sales Analysis Dashboard

## Overview
This project analyzes an e-commerce retail dataset to uncover key business insights related to sales and profit using Python.

The goal is to help businesses understand which categories, products, and regions perform best.

---

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## Dataset
- Sample Superstore Dataset (Kaggle)

---

## Key Insights

### Sales Analysis
- Technology category has the highest sales (~836K)
- Furniture and Office Supplies follow closely
- Sales distribution shows Technology as the top-performing category

### Profit Analysis by Region
- West region contributes the highest profit (~37.9%)
- East region is second (~32%)
- South and Central regions contribute less profit

### Top 5 Sub-Categories by Sales
1. Phones (~330K)
2. Chairs (~328K)
3. Storage (~223K)
4. Tables (~206K)
5. Binders (~203K)
